RÉSUMÉ DU JEU (détails dans la charte)
- Gardien de nuit, 23h → 5h, surveillance d'une maison via caméras.
- Images fixes 2D par pièce + filtre caméra de surveillance.
- 3 types d'anomalies : objet ajouté, objet retiré, anomalie visible.
  Bouton ANOMALIE → choix du type → analyse 2-3 s → bon = retour à l'image
  de base ; mauvais = -1 vie.
- Vies à 0 → pièce secrète, allumer la lumière → screamer.
  6 pièces anormales en même temps → screamer → game over.
- Facile 5 vies / 8 cams, Normal 3 vies / 10 cams, Difficile 3 vies / 12 cams.
  Pièces tirées au hasard et ordre des caméras mélangé à chaque partie.
- RÈGLE D'OR : une image ne change JAMAIS sous les yeux du joueur. Changement
  uniquement si personne ne regarde la caméra ou pendant le noir complet d'un
  clignement d'œil réaliste (synchronisé en coop).
- Menu style FNaF : Solo, Héberger, Rejoindre, Options, Crédits. Coop avec
  état partagé. Aucune progression/monétisation pour l'instant.
